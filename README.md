# E2EPOMFramework

Enterprise Playwright Automation Framework.

## Application

https://the-internet.herokuapp.com/

## Technology Stack

- Playwright
- TypeScript
- Node.js
- Allure Reports
- GitHub Actions
- Azure DevOps
- AI-assisted development

## Architecture

- Page Object Model
- Custom Fixtures
- Data-driven Testing
- API Automation
- Multiple Browser Contexts
- Reusable Utilities

npm install

npx playwright install

npm test

npm run test:headed

npm run test:chromium

npm run test:ui
